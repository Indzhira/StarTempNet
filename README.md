# Прогнозирование температуры звезды с помощью нейронной сети

Модель разработана как вспомогательный инструмент: она позволяет быстро получить предварительную оценку температуры новых звёзд до проведения спектрального анализа и физических расчётов (например, по законам Вина или Стефана–Больцмана).

**Цель:** предсказание абсолютной температуры поверхности звезды (в Кельвинах) по её наблюдаемым астрофизическим характеристикам.

## Научная ценность
Модель предназначена для использования в обсерватории в качестве инструмента предварительной оценки температуры новых обнаруженных звезд. Ее использование помогает решить следующие задачи: 
* Ускорение первичного анализа.
* Фильтрация: модель помогает выделить аномальные объекты, где прогноз сильно расходится с ожиданием. Такие звёзды стоит изучить детальнее.
* Снижение нагрузки на вычислительные ресурсы.

## Данные
**Источник:** Яндекс Практикум (учебный датасет)

**Описание:** Характеристики звезд: относительная светимость `L/Lo`, относительный радиус `R/Ro`, абсолютная звездная величина `Mv`, звездный цвет,
тип звезды, абсолютная температура `T(K)` на поверхности звезды.

**Ограничения:** Датасет содержит всего 240 объектов, это накладывает ограничения на сложность модели и требует аккуратной регуляризации.

## Постановка задачи
**Целевая переменная:** температура поверхности звезды (в Кельвинах).

**Тип задачи:** регрессия с метрика качества `RMSE`.

## Основные этапы работы
* Загрузка данных
* Предобработка данных
* Исследовательский анализ и корреляционный анализ данных
* Построение базовой модели - простая полносвязная нейронная сеть.
* Улучшение модели: применение `Batch Normalization`, `Dropout` и подбор размера батча.
* Выводы

## Результаты
**Достигнутая метрика**: `RMSE = 3750.34K` на тестовой выборке.

**Качество прогноза:** Модель дает оценки температуры с приемлемой точностью для предварительной фильтрации кандидатов.

**Ключевые выводы по экспериментам:**

* Функция активации `ELU` показала лучший результат среди протестированных.
* `Batch Normalization` при текущем объеме данных ухудшает качество прогноза.
* Совместное применение `Dropout` и подбор размера батча позволили добиться небольшого улучшения `RMSE` (около 22К).

**Ограничения и перспективы:**

* Главный фактор, сдерживающий рост качества, - небольшой объем данных (240 объектов). Для дальнейшего улучшения метрик требуется расширение датасета.
* Возможные направления развития: подбор других архитектур, более тонкая настройка гиперпараметров.
  
**Практическая ценность:** Модель можеть быть использована обсерваторией для предварительной оценки температуры новых обнаруженных звезд до проведения спектрального анализа и других более трудоемких расчетов.
